# Facts packs

One file per working session, named `YYYY-MM-DD-<topic>.md`. Each is a self-contained record meant to be
read **without** the conversation that produced it, and to be laid beside the packs from other sessions and
analysed together.

The one rule that makes them worth collecting:

> **Measurements, derivations and readings are kept in separate sections, and never merged.**

A measurement is a number a run produced. A derivation is arithmetic on measurements, with the arithmetic
shown so it can be rechecked. A **reading** is an interpretation — it is one person's account of what the
numbers mean, it is the part most likely to be wrong, and it is the part a later analysis must be free to
discard. Anything that cannot be traced to a run belongs in *Readings* or in *Open*, never in *Measured*.

Corollary: when a pack records a prediction, it records who registered it, when, and in which commit —
so that a pre-registration can be verified against the history rather than asserted.
