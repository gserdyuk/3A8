## Findings

1. **The assembler's special-count parser misses common phrasings** ("so the class is **M**", "**Count: 2. Class:
   M.**", "**L01, count 2, M.**"). Unfixed, it silently turns assigned classes into holes. Candidate for
   `tools/chain` (this session changed no tool).
2. **The consolidator's group parser** misses "`**NAME** is the …`" (run 62) — same kind of defect.
3. **L56 is unsizeable in both repeats** — the model's F47 leaf declares a set it never names; the sensors asked for
   an inventory of the first version's core functions (closure violation in HD63-D1).
