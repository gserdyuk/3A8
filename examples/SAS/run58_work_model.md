classes distribute as they did in run 47. A total near ×1.0 would mean the size classes moved up; below ×0.85
would mean the per-parent rates weigh more than the item counts suggest.

   sees the obligation texts and will count what A9 lost.

   A025, A146, A147), NFR-16 (A008, A020, A081, A165), NFR-17 and NFR-18 (A037, A167): four sensors named this

   Batch D listed the alternative (behaviour: six fewer A10 items). This is the first price-bearing consequence
   of the 2.1 identity sentence, and the sizing step will show the second.
4. **The read store has no store element in three batches.** A029 (batch C), A133 (batch G) and the batch A
   sensor all name a "read store" that lives in `A143` under N03 — correct for the model, invisible from a partial
   run. Not a gap; recorded because three sensors raised it.

   did.
6. **`DW-4` stands.** The support period of W-4 is absorbed by no declared activity and was entered as a demanded
   branch without an activity — the same reading run 45 reached by way of the assumption log. Counted once at

7. **A prompt defect of this run, harmless.** The INPUT 1 paragraph names `CN01` in every batch although it is in
